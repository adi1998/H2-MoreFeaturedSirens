## Featured Sirens

Hades II mod allowing more than one Siren to be featured in phase 2.

## Configuration

Default config is setup to feature all Sirens in the fight. Can be configured to be lower in the r2modman config manager after the game has been launched modded atleast once.

## Installation

Use r2modman by ebkr from [Thunderstore](https://thunderstore.io/package/ebkr/r2modman/) or [GitHub](https://github.com/ebkr/r2modmanPlus/releases/latest).

It is recommended to backup your save from `%USERPROFILE%\Saved Games\Hades II\Profile*.sav` in case there are unknown issues with the mod.
